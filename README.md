# 🚦 Traffic Engineering Problems

**Python programs that solve classic traffic and transportation engineering problems: queues, speed and volume studies, traffic flow models, modal split, highway design, safety and economics.**

## ⚙️ Getting started

Clone just the topic you need (swap in any branch name from the table above), install the packages listed in that branch's README, and run a program:

```bash
git clone -b Queuing-Analysis --single-branch https://github.com/shreyanspeaking-arch/Traffic-Engineering-Problems.git
cd Traffic-Engineering-Problems
pip install pandas numpy sympy matplotlib openpyxl
python M_M_1_Queuing_Model.py
```

Every program is interactive: it asks for its inputs one at a time in the terminal.

## 📝 About the sample data

- Most or all of the sample input `.csv` files are **AI generated**. Some contain random but realistic data for testing a program; others were created from photos of printed tables in sample problems from textbooks.
- Several tables are standards from sources such as the Transportation Research Board (TRB) and AASHTO, for example the crash analysis factors used in the Traffic Safety Analysis branch.
- Sample outputs are mostly `.xlsx` files named `output<no>.xlsx`; graphs made with `matplotlib` are saved as `.png`. The commit message of each output file says which program and input created it.

## 🗄️ Original-Branch-Disorganized

- This sub branch has the original copies of all the programs, their sample input, their sample output and other files (mainly .csv files) required for their functioning.
- It keeps every program in this repository in one place; the other sub-branches separate these programs by type and purpose.
- The commit history of some files in the other sub-branches is incomplete, because every file was uploaded here first and then copied into the topic branches. To see a file's full history, open the file with the same name in this branch.
