The programs below were added to this repository as of 15th September, 2026. Every file was uploaded to this branch first and then copied into the topic branches, so **this is the place to check a file's full commit history**.

## 📝 About the files

- All files that are not `.py` files are sample inputs or sample outputs of the programs below. The commit message of each file gives its details.
- Most or all of the sample input `.csv` files are **AI generated**, either from prompts asking for realistic random data to test a specific program, or from photos of printed tables in sample problems from books.
- Many AI generated `.csv` tables are standards collected from sources like the Transportation Research Board (TRB) and AASHTO, e.g. the crash analysis factors used by [Traffic_Safety_Analysis_at_a_4_signal_intersection.py](https://github.com/shreyanspeaking-arch/Traffic-Engineering-Problems/blob/Original-Branch-Disorganized/Traffic_Safety_Analysis_at_a_4_signal_intersection.py).
- Output tables are mostly `.xlsx` files named `output<no>.xlsx`, and graphs made with `matplotlib.pyplot` are `.png` files. Check the commit section for where each came from.
